## 5. Unit-wise Internal Movement

- Corrected bulk movement handoff from the Instrument Master to Create Movement.
- Selected records are now staged automatically when Create Movement opens.
- Enforced the one-instrument/one-asset movement model.
- Internal movement now follows the client-required rack lifecycle:
  - Source rack becomes empty immediately after issue.
  - Instrument status becomes **In Movement**.
  - Current unit/rack is cleared while in transit.
  - Transit description records `Unit 1 → Unit 2` or the applicable units.
  - Destination rack/location is mandatory during receipt.
  - Destination ownership is assigned only after receipt.
- Movement cancellation restores the original unit and source rack.
- Instrument details now display the active movement summary:
  - Moved from
  - Destination unit
  - Source rack/location
  - DC number
  - Movement date
  - Expected receipt date
  - Issued-to details
  - Destination rack pending receipt
