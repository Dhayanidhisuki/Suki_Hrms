### C3. Calibration Issue — Consider Date / From–To UX

**File:** `src/app/dashboard/calibration/issue/page.tsx`

**Problem:** From/To were `disabled` while Consider Date = No (default), so date pickers looked broken.

**Fix:**
- From/To always clickable
- Choosing a date auto-sets **Consider Date → Yes**
- Switching Consider Date → **No** clears dates
- Clear dates also resets Consider Date → No

**Smoke:** Issue for Calibration → open calendar on From Date without first flipping Consider Date; list filters when Yes.

### C4. Transaction Overview — duplicate React key `trend`

**File:** `src/components/OverviewCharts.tsx`

**Problem:** Soft fill `<Area>` and dashed `<Line>` both used `dataKey="trend"` → Next overlay “Encountered two children with the same key, `trend`” (repeated ≈9×).

**Fix:**
- Separate series field `trendArea` for Area fill; Line keeps `trend`
- Tooltip row keys: `dataKey + name + index`
- Week labels disambiguated (`Th` / `Sa` / `Su`)

**Smoke:** `/dashboard/overview/transactions` loads without the 1/9 console error overlay.
