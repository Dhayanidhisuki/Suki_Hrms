# SUKI Tools Management — Work Log

**Date:** 11 August 2026  
**Scope:** Client-focused Instruments & Gauges management, calibration, unit movement, imports, DC documents, notifications, defects, and history.

## Client Direction Confirmed

- Client manages instruments and gauges only.
- Calibration is performed by authorized external agencies.
- Internal issue/receive workflow is presented as **Movement**.
- Movement is unit-wise between Unit 1, Unit 2, and Unit 3.
- Each identification number represents one physical instrument; users do not manage stock quantities.
- Existing ERP tables, fields, and legacy routes remain intact for compatibility.
- Tool Master list must follow the client's calibration register columns.
- `Validity (days)` is application-calculated as `Next Calibration Due - current date`; it is never imported or stored.
