## Part D — Calibration results visibility triage (late day)

**Session:** Calibration results visibility  
**Tools in play:** `MPTRG 00054`, `OTH_C01242`

### D1. User problem

After Results Update / receive:
- Expected data on Item/Asset Master and Tools History Card
- History Card search `MPTRG 00054` → **0 of 0**
- Item/Asset Master search → empty + KPIs **0** (Active filter)
- Results Update modal showed **Next Calib = 2020** while Calibrated Dt = 2026-08-06

### D2. Write path clarified (not a missing save)

`POST /api/calibration/results-update` writes:

| Target | Stored |
|--------|--------|
| `TOOLS_TRANS_ISSUE_FOR_CALIBRATION` | Result, dates, next due, packed comments |
| `GAUGE_CONTROL_CARD` + `_TRANS` | Last/next history |
| `GAUGEANDTOOLS` | **Status** (+ optional location) only — not a full result archive on the master form |

Unit Last/Next dates show on History Card / master **serial grid** when units exist.  
History Card **Calibration Results** page still defaults to **open/pending** queue (completed rows drop off — known gap; use Results Update → Closed).

### D3. Next Calib default bug — **code fix**

**Root cause:** API exposes `nextCDate = nxtCalibDate ?? calibDueDate ?? dueDate`. Pending lines have empty `nxtCalibDate`, so **old overdue due** (e.g. 2020) fills the form. Modal used any truthy fetched value instead of `calibrated + frequency`.

**File:** `src/app/dashboard/calibration/results-update/page.tsx`

- `suggestNextCalibDate` / `resolveNextCalibDefault` — use fetched next only if **after** calibrated date; else calibrated + frequency (fallback 6 months)
- Changing Calibrated Dt. refreshes Next when blank or still ≤ calib date
- Helper hint under the field

### D4. `MPTRG 00054` enablement — **data fix** (refNo 2408)

| Field | Before | After |
|-------|--------|--------|
| `historyCardReq` | No | **Yes** |
| `calibrationFrqMonths` | 0 | **6** |
| `activeItem` | No (hidden by Active: Yes) | **Yes** |
| Unit status | ISSUE FOR CALIBRATION | **Available** |
| Result line `nxtCalibDate` | 2020-03-18 | **2027-02-06** |
| Control card frequency / history | 0 / empty | **6** + trans row |

### D5. API robustness

**File:** `src/app/api/tools/route.ts`  
`historyCardOnly` accepts `historyCardReq` in `["Yes", "Y", "YES"]` (same as calibration-due).
