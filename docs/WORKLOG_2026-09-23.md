## 6. Visual Org Chart — new component

`src/components/masters/OrgChartCanvas.tsx` — the dark hierarchy-canvas view
from the Stitch design, now the default view on Reporting Structure
alongside the existing Tree and Table views.

- Hand-written tidy-tree layout (~40 lines, no charting library) — measure
  pass then place pass, centers each parent over its children.
- Node cards with initials-avatar, designation, hashed-color department
  chip, collapsible direct-reports pill.
- Chrome bar: depth/node-count readout, `− 100% + Fit` zoom, **Download**.
- **PNG export**: `html2canvas` (was already a transitive dep via
  `jspdf`, now made explicit in `package.json`/lockfile). Captures the
  *entire* chart at 2× resolution regardless of current scroll/zoom — the
  CSS zoom transform is cleared right before capture and restored right
  after, since rasterizing through a live transform crops/mis-scales.
- Collapse state is shared between the Chart and Tree views (one `Set`,
  derived both ways) so collapsing a branch in one view stays collapsed in
  the other.
- Caught and fixed one bug before it shipped: the layout's `measure()`
  function was double-counting nodes/depth because `place()` calls it again
  — made it pure.
