## 8. Calibration Observation Code Synchronization

Updated Calibration Results entry so the field is clearly labelled:

**Error / Observation Code**

When a result is saved:

- The full structured value remains in calibration result history.
- The value continues to update Instrument Master Observed Error.
- The value is copied to `GAUGEANDTOOLS.REMARKS` for the Tool Master Remarks column.
- The master remark is limited safely to the ERP column length of 50 characters.
- Existing master remarks are preserved when no new observation code is entered.
- The Tool Master Remarks cell falls back to the structured observed-error value when necessary.
