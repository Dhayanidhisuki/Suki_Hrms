## Part D — Tools Master PDF export blowout

### D1. Audit

- Button: Item/Asset Master → Export PDF → `GET /api/tools/export?format=pdf`
- Library: **jsPDF + jsPDF-AutoTable** via `buildPdfBuffer` in `src/lib/serverReportExport.ts`
- Cause: 16 narrow landscape columns + default `overflow: 'linebreak'` + space-less / pipe-joined `SERIAL_NO` & `MAKE` → character-per-line wrap → ~7,305 pages for ~13,803 rows
- Data: multi-unit `joinPipe` is intentional; Excel uses same row map but does not paginate the same way
- `/api/reports/tools` shares the PDF builder but does not export `SERIAL_NO`

### D2. Fix

In `buildPdfBuffer` only (Excel / queries unchanged):

- Truncate cells to **40 chars** + ellipsis (`truncateForPdfCell`)
- AutoTable `overflow: "ellipsize"`, single-line cells

### D3. Stress retest (synthetic worst-case long SERIAL_NO/MAKE)

| Metric | Before (user report) | After |
|--------|----------------------|-------|
| Records | 13,803 | 13,803 |
| Pages | ~7,305 | **~395** |
| Rows/page | ~1–2 | ~35 |
