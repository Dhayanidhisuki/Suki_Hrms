### 2. Subcontractor Master — empty UI fix
- **Cause:** Prisma model used `subConId` without `@map("SUB_CON_ID")`; queries
  failed (`Invalid column name 'subConId'`). UI also expected booleans /
  Active|Inactive while ERP stores Yes/No and ACTIVE/BLOCKED.
- **Fix:**
  - Mapped `Subcontractor` to proven ERP columns (`SUB_CON_ID`, `SUB_NAME`,
    flags, address, status, audit fields).
  - Remapped list/detail APIs to UI shape (`id`/`subCode`, booleans, Active).
  - Regenerated Prisma client and restarted Next (global Prisma client kept the
    stale mapping until process restart).
- **Verified:** `/api/subcontractors` returned live rows (hundreds of records).

### 3. Calibration submodules — remapped to ERP
- **Issue list broken:** phantom `STATUS` on `TOOLS_ISSUE_FOR_CALIBRATION`
  header (column does not exist in ERP) → API 500.
- Removed header `status`; derive OPEN/PARTIAL/CLOSED from receive headers /
  line result fields.
- **Due List / Results** were empty because `GAUGE_CONTROL_CARD(_TRANS)` has
  little/no ERP data. Primary source switched to
  `TOOLS_TRANS_ISSUE_FOR_CALIBRATION` (`NXT_CALIB_DATE` / `CALIB_DUE_DATE` /
  `DUE_DATE`), with control-card as optional enrichment.
- Results Update: GET pending lines + POST updates line result fields; control
  card write is best-effort.
- Receive: keep ERP receive history; surface **open issues awaiting receive**
  when receive table is empty.
- Overview: live KPI cards wired to calib APIs.
- **Verified live counts (approx.):** Issue 29 · Due 143 · Pending results 136 ·
  Open awaiting receive 21 · Gauge types 31 · Calib frequency 3 · Receive
  history 0 (ERP empty).
