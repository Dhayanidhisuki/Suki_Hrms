# Worklog — 26 Jul 2026

## Summary
Redesigned the dashboard Sidebar and TopBar to match the Suki CRM's visual
language, then wired up a theme-aware brand logo.

## Details

### 1. Sidebar / TopBar redesign (CRM parity)
- `src/app/dashboard/components/Sidebar.tsx`
  - Converted nav sections from "always-expanded tree" to CRM-style accordion
    (single section open at a time, chevron up/down).
  - Added CRM-style hover accent (left border + background tint) via inline
    style handlers, matching CRM's interaction pattern.
  - Replaced solid active-state fill with a subtle tinted background
    (`--sidebar-active-bg`).
  - Redesigned user profile footer as a rounded card (avatar, name, logout
    icon button).
- `src/app/dashboard/components/TopBar.tsx`
  - Added profile dropdown menu (Profile / Settings / Sign Out) with
    click-outside-to-close behavior.
  - Added notification bell dropdown (CRM-style dark header, "Live"
    indicator, empty state).
  - Restyled search input and icon buttons to match CRM's pill/rounded style.
- `src/styles/themes.css`
  - Added `--sidebar-heading`, `--sidebar-active-bg`, `--topbar-bg`,
    `--topbar-border` CSS variables to support the new styling.

### 2. Sidebar nav label change
- `src/app/dashboard/components/Sidebar.tsx`: renamed "Main" section to
  "Home".

### 3. Theme-aware brand logo
- Identified 4 provided logo SVGs in `public/` correspond to the app's 4
  accent themes (matched by gradient hex codes against `themes.css`):
  - `logo-blue.svg` (was `Group 254.svg`) → blue theme
  - `logo-green.svg` (was `Group 261.svg`) → green theme
  - `logo-purple.svg` (was `Group 260.svg`) → purple theme
  - `logo-orange.svg` (was `SUKI.svg`) → orange theme
- Renamed files (removed spaces for URL safety).
- `Sidebar.tsx`: reads `theme` from `useTheme()` and swaps the logo
  automatically; full wordmark shown expanded, cropped icon-only crop
  shown collapsed.
- `next.config.ts`: added `images.dangerouslyAllowSVG: true` (required for
  Next's image optimizer to serve local SVGs).
- Restarted dev server (port 3000) to apply the config change.
