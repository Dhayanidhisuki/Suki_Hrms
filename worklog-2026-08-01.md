## Session B — Transactions, Receive scale, History Card, practice guide

### 1. Tool Issue — form + API (`GAUGE_TOOLS_ISSUE`)
**Symptoms during smoke test:** “Return due date is required” with date visible; “1 / 0 avail” after staging; submit would fail Zod / ERP constraints.

**Fixes:**
- Default **Issue Date** and **Return Due Date** to local today; clear form keeps both set.
- Payload now sends `issueDate`, `dueDate`, `empId` (default `0`), `partNo` (= tool no).
- `ToolsIssueCreateSchema`: optional `empId` (coerce, default 0), optional `partNo`.
- API: `resolveErpAuditUserId` for `CREAT_USER_ID_CD`; supply non-identity `TOOLS_TRANS_ISSUE.ROW_ID` as max+1; schema `@default(autoincrement())` removed.
- Stock panel shows staged `qtyAvailable` snapshot (not cleared search list).

**Files:** `src/app/dashboard/transactions/issue/page.tsx`, `src/app/api/issue/route.ts`, `src/lib/validators.ts`, `prisma/schema.prisma`

### 2. Tool Receive — “Request failed” on TS-J000104
**Root causes:**
- Legacy issue lines with `TOOL_OR_GAUGE_NO = null` → Zod + client keyed by tool no.
- `REC_NO` / receive-line `ROW_ID` **not identity** in ERP.
- `CREAT_USER_ID_CD` FK → `ERP_USER` (app login `admin` invalid).
- Generic “Request failed” when API returned Zod flatten objects.

**Fixes:**
- Client keys return qty by **issue `rowId`**; payload sends `issueRowId`.
- API resolves tool no when present; skips stock update if no master; supplies `recNo` / `rowId`; ERP audit actor; Closed vs PARTIAL status.
- Schema: remove false autoincrement on receive header/lines.
- `apiClient.formatApiError` surfaces Zod field errors.

**Files:** `src/app/api/receive/route.ts`, `src/app/dashboard/transactions/receive/page.tsx`, `src/lib/validators.ts`, `src/lib/apiClient.ts`, `prisma/schema.prisma`

## Key decisions

1. ERP audit writes always go through `resolveErpAuditUserId` — never app username alone.
2. Never assume SQL Server identity on ERP `ROW_ID` / `REC_NO` — always max+1.
3. History Card module lists only `HISTORY_CARD_REQ = Yes`.
4. Purchase practice path = **Supplier master + GRN**; PO create stays out of scope.
5. Large open-DC lists are paged/searched — never dump full ERP set into the browser.
